Perkakas format & konversi

Semua berjalan di browser Anda. Tidak ada data yang dikirim ke server mana pun.

Formatter

  • JSON Formatter Menyusun ulang JSON dengan indentasi dua spasi sekaligus memeriksa kesahihannya. Bila ada kesalahan sintaks, posisinya ditunjuk sampai baris dan kolom.
  • HTML Formatter Menata indentasi HTML mengikuti kedalaman tag. Tag tanpa penutup seperti img dan br tidak menambah kedalaman.

Minifier

  • JSON Minifier Membuang seluruh spasi dan baris baru dari JSON. Masukan diurai lebih dulu, jadi hasilnya dijamin JSON yang sah — bukan hasil potong-potong teks.
  • CSS Minifier Pemadat yang sengaja dibuat konservatif: hanya membuang komentar dan spasi yang pasti aman, tanpa menyentuh isi properti Anda.

Validator

  • JSON Validator Memeriksa apakah JSON sah. Kalau tidak, kesalahan ditunjuk pada baris dan kolom tertentu dengan cuplikan barisnya. Kalau sah, ditampilkan ringkasan strukturnya.

Konverter

  • JSON ke XML Mengubah JSON menjadi XML. Larik menjadi elemen berulang dengan nama tag yang sama.
  • Timestamp Converter Mengubah Unix timestamp menjadi tanggal terbaca, atau tanggal menjadi timestamp. Detik dan milidetik dikenali otomatis, dan tiap baris diproses sendiri-sendiri.

Encoder

  • Base64 Menyandikan dan membuka sandi Base64 lewat UTF-8, sehingga huruf beraksen dan aksara non-Latin tidak rusak.
  • URL Encoder Menyandikan teks menjadi percent-encoding dengan encodeURIComponent, cocok untuk NILAI parameter — bukan untuk alamat utuh.
  • HTML Escape Mengubah <, >, &, dan tanda kutip menjadi entitas HTML agar aman ditampilkan sebagai teks biasa.
  • XML Escape Escape dan unescape memakai lima entitas baku XML: &amp;, &lt;, &gt;, &quot;, dan &apos;.

Lainnya

  • Regex Tester Menguji pola regular expression JavaScript pada teks. Tiap kecocokan dilaporkan dengan baris, kolom, dan isi grup penangkapnya.
Tiap alat punya berkas HTML dan alamatnya sendiri. Berpindah alat memuat ulang dokumen sepenuhnya seperti situs biasa, bukan menukar isi halaman lewat JavaScript.
