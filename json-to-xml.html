JSON → XML

Mengubah JSON menjadi XML. Larik menjadi elemen berulang dengan nama tag yang sama.

1
Hasil 

          
        

      


      

        
        
        
        
        
        
      


      

      


      
Larik menjadi elemen berulang dengan nama tag yang sama. Nama kunci yang tidak sah sebagai tag XML dibersihkan otomatis, dan karakter &, <, > pada nilai di-escape.

      
Batasan alat ini. XML tidak mengenal larik, jadi [1,2] pada kunci a menjadi dua elemen <a> berurutan — bentuk ini tidak bisa dibalik ke JSON tanpa kehilangan informasi. Kunci yang mengandung karakter di luar huruf, angka, _, ., dan - diganti _.


      

        Berkas yang Anda unggah dibaca lewat FileReader di peramban ini dan tidak dikirim ke mana pun.
